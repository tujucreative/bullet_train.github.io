# Bullet Train Docs Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static GitHub Pages site in `tujucreative/bullet_train.github.io` that renders the Bullet Train v1.45.1 developer docs with a close replica of the bullettrain.co/docs layout.

**Architecture:** A plain-Ruby builder (`lib/docs_site/`) renders vendored markdown (`src/docs/`) with the exact Commonmarker call that the Rails app uses. Nokogiri rewrites links for a configurable base path, and an ERB layout plus Tailwind v3 CSS wrap each page into `_site/`. GitHub Actions tests, builds and deploys.

**Tech Stack:** Ruby 3.3, commonmarker >= 2.7, nokogiri, minitest, rake, webrick; Node 22, tailwindcss 3.4, @tailwindcss/typography, @tailwindcss/forms, @icon/themify-icons; GitHub Actions (configure-pages, upload-pages-artifact, deploy-pages).

**Spec:** `docs/superpowers/specs/2026-11-06-docs-site-design.md`

1. 5. A future `bin/sync-docs` that brings in a page linking to a non-existent doc fails the build with a message naming the page and the href, rather than shipping a 404. Pinned in Task 6.

### Task 2: Renderer and LinkRewriter

**Files:**
- Create: `lib/docs_site/renderer.rb`, `lib/docs_site/link_rewriter.rb`, `test/renderer_test.rb`, `test/link_rewriter_test.rb`

**Interfaces:**
- Consumes: `DocsSite::Config#doc_url`, `#asset_url`, `#base_path`.
- Produces: `DocsSite::Renderer.render(markdown) -> String`, which forces the input to UTF-8 with `dup.force_encoding("UTF-8")` and applies the Global Constraints call verbatim.
- Produces: `DocsSite::Renderer.render_file(path) -> String`, which reads with `File.read(path, encoding: "UTF-8")`.
- Produces: `DocsSite::LinkRewriter.new(config).rewrite(html, slug:) -> String`. `slug` is the current page's slug and is used to resolve relative hrefs.

Rewrite rules for each `a[href]` and `img[src]` (parse as a fragment with `Nokogiri::HTML5.fragment` or `Nokogiri::HTML::DocumentFragment`, then serialize with `to_html`):
1. If the value starts with `https://bullettrain.co/upgrade-images/<file>`, replace it with `asset_url("upgrade-images/<file>")`.
2. If it starts with `https://bullettrain.co/docs`, drop the origin and treat it as an absolute path (rule 4).
3. If it's relative (no scheme, doesn't start with `/` or `#`), resolve it with `URI.join("https://h/docs/#{slug}", href)`. If the resulting path starts with `/docs`, take that path plus the fragment and continue with rule 4. Otherwise leave it alone.
4. If the path is `/docs` or `/docs/...`, strip one trailing `/` and a trailing `.md`, take the slug after `/docs/` (empty means `index`), and output `doc_url(slug)` plus `#fragment` if present.
5. Leave everything else unchanged.

**Files:**

**Interfaces:**
- Consumes: `Config#doc_url`, `Config#site_url`.
- Produces: `DocsSite::Page.new(slug:, html:, config:)` with readers `slug`, `html`, and methods `url` (`config.doc_url(slug)`), `output_path` (`"docs/index.html"` or `"docs/#{slug}/index.html"`), `absolute_url` (`config.site_url + url`), `title`, `page_title`, `description`.

- Produces: `DocsSite::Page::SITE_NAME = "Bullet Train Developer Documentation"`.
- Produces: `DocsSite::IndexLayout.apply(html) -> String` and `DocsSite::IndexLayout.in_groups(array, n) -> Array<Array>`.

Metadata rules, ported from the live `docs.html.erb` head:
- `title` is the first `h1`'s text, stripped. If that's blank, use `SITE_NAME`.
- `page_title` is `[SITE_NAME, title].uniq.reverse.join(" — ")`.
- `description` is `[text of the h2 preceding the first p (xpath "preceding-sibling::h2", last one), first p text].reject(&:empty?).join(" — ")`, truncated to 200 characters with `"..."` replacing the tail when longer. If there's no paragraph, use `SITE_NAME`.

IndexLayout ports the `docs.html.erb` index branch. Split at the first `<h2>` into a header and groups. Re-prefix each group with `<h2>`. Distribute the groups with `in_groups(groups, 3)` and output `header + '<div class="xl:grid grid-cols-3 gap-20">' + 3 × "<div>#{group.join}</div>" + "</div>"`. `in_groups` matches ActiveSupport without fill: with `q, r = size.divmod(n)`, the first `r` groups get `q+1` items and the rest get `q`. If there's no `<h2>`, return the html unchanged.
